# 문서 관리: 선택한 문서를 다른 제품군의 모델로 이동·복사·삭제

챗봇용 문서 관리(제품군 › 모델 › 문서)에서, 이미 입력한 문서를 지우고 다시 입력하지 않고 다른 모델로 옮기거나 복사하는 기능입니다.
(원본 자료실과는 별개입니다. "폴더"라는 말이 나오면 원본 자료실이 아니라 이 문서 관리를 뜻할 수 있으니 불분명하면 먼저 물어봅니다.)

## 사용 방법
1. 문서 관리에서 모델의 문서 목록을 펼치고 **문서 체크박스**를 체크합니다. (여러 모델·여러 제품군의 문서를 함께 체크해도 됩니다. 「이 모델 문서 전체 선택」, 위쪽 「전체 선택」도 사용 가능)
2. 체크하면 그 모델의 **"이 모델 문서 전체 선택" 줄 오른쪽**에 작업 막대(`선택 N건 / ⬇ 선택 문서 다운로드 / 🗑 삭제 / ⧉ 복사 / ↔ 이동`)가 바로 나타납니다. 맨 위로 스크롤하지 않아도 되고, 그 줄은 스크롤해도 화면 위쪽에 붙어 있습니다. (위쪽 다운로드 막대에도 같은 버튼이 있으며 체크한 문서가 없으면 잠깁니다. 막대의 동작은 모델과 관계없이 **체크한 문서 전체**에 적용되고, 다른 모델의 문서도 체크돼 있으면 "(다른 모델 포함)"이라고 표시됩니다.)
3. 창에서 **제품군 → 모델**을 고릅니다. (모델이 없는 제품군은 고를 수 없음)
4. 확인 창의 안내(옮길 문서 수, 접근 그룹 변화)를 보고 「이동」/「복사」를 누릅니다.

- 이동: 체크한 문서의 소속 모델(`documents.model_id`)만 바뀝니다. 내용은 그대로입니다.
- 복사: 원본은 그대로 두고 새 번호로 문서를 만듭니다(내용·사진 자리표 그대로, 사진 파일은 함께 사용). 복사 중 저장 오류가 나면 만든 것을 지우고 취소합니다.
- 이미 대상 모델에 있는 문서는 자동으로 제외되고, 같은 제목·분류의 문서가 이미 있으면 알려줍니다(중복되어 보일 수 있음).
- 이동 도중 저장 오류가 나면 거기서 멈추고, 이미 옮긴 문서는 그대로 반영됩니다("N건만 이동하고 저장 오류로 멈췄습니다").
- **삭제**: 확인 창(건수·목록 일부)을 거쳐 DB에서 실제로 삭제합니다(되돌릴 수 없음). 저장 오류가 나면 거기서 멈추고 지운 만큼만 반영됩니다. 문서 입력창 안의 「삭제」도 이제 DB에서 실제로 삭제합니다(예전에는 화면에서만 지워지고 새로고침하면 다시 나타났음). 문서 속 사진 파일은 저장소에 남습니다.
- 끝나면 선택이 해제되고 대상 모델의 문서 목록이 펼쳐져 결과를 바로 볼 수 있습니다.
- DB 구조 변경은 없습니다(운영 SQL 실행 불필요).

## 접근 권한 (중요)
사용자 그룹의 접근은 **제품군 단위**(`group_products`)로 정해져 있어서, 문서가 다른 제품군으로 가면 그 문서를 보는 그룹이 달라집니다.
확인 창에서 **지금 보는 그룹 / 이동 후 보는 그룹**을 보여 주고, 대상 제품군을 볼 수 있는 그룹이 하나도 없으면 "일반 사용자에게는 보이지 않음" 경고를 띄웁니다. 같은 제품군 안에서의 이동은 "접근 권한은 그대로"라고 안내합니다. 관리자는 항상 모두 볼 수 있습니다.

## 시험
`node tests/doc-move/e2e.js` (가짜 DB, 브라우저 42개)

## 문서 사용 켜기/끄기 (눈 아이콘)
- 문서 목록의 각 문서 오른쪽에 **눈 아이콘**이 있습니다(문서 입력창의 등록된 문서 목록에도 있음). 누르면 그 문서를 **챗봇이 답변에 쓰지 않도록 끄고**, 다시 누르면 켭니다. 끈 문서는 흐리게 + "사용 안 함" 표시가 되며, 문서 자체는 그대로 보관되고 다운로드·이동·복사·삭제도 그대로 가능합니다.
- 끈 문서는 AI에게 전달하는 문서 내용에서 빠지고, 문서 번호(참조 표시)도 켜 둔 문서 기준으로 다시 매겨집니다. 모든 문서를 끄면 "등록된 문서 없음"으로 동작합니다. 복사하면 끈 상태도 함께 복사됩니다.
- DB: `documents.enabled boolean not null default true` (기본값이 사용이라 기존 문서에는 영향 없음). **운영 SQL 필요: `docs/sql/doc_enabled_01.sql`** (적용 전에는 눈 아이콘을 눌러도 "DB 저장 실패" 안내만 나오고 아무것도 바뀌지 않음).
- 사용자 화면의 모델 선택 목록에서는 "(문서 N건)" 표시를 없앴습니다. 챗봇 상단/환영 문구의 문서 건수는 켜 둔 문서 기준으로 표시합니다.
- 시험: `node tests/doc-enabled/e2e.js` (브라우저 20개)

## 눈 아이콘 / 작업 중 표시 (추가)
- 눈 아이콘을 눌러도 펼쳐 둔 제품군·모델 문서 목록은 접히지 않고(`_catOpen`, `_docOpen`) 스크롤 위치도 유지된다. 저장되는 동안 눈 아이콘이 돈다.
- 모든 DB 저장·불러오기, 자료실 서버 호출(`dbQ/dbIns/dbUpd/dbDel/dbUps`, `libApi`)은 `withBusy`를 거쳐, 진행 중에는 화면 맨 위 막대와 "작업 중입니다…" 알림(0.25초 넘게 걸릴 때)이 나온다.
