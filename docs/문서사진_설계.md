# 문서 사진 (챗봇 답변에 사진 함께 표시)

모든 제품군·모델의 문서에 화면 캡처 같은 사진을 넣고, 챗봇이 해당 설명과 함께 사진을 보여 주는 기능입니다.
(원본 자료실과는 별개입니다. 자료실은 PDF/이미지 열람 메뉴, 이것은 챗봇 답변용 사진입니다.)

## 동작 방식
1. 관리자가 문서 입력창에서 **🖼️ 사진 넣기**(또는 캡처 붙여넣기 Ctrl+V, 끌어다 놓기)를 하면
   - 브라우저가 사진을 가로 700/1000/1600px 이하의 WebP(안 되는 브라우저는 JPEG, 품질 72%)로 줄이고
   - 서버(`/api/doc-image-upload-url`, 관리자만)에서 **서버가 정한 무작위 파일명 + 그 이름에만 올릴 수 있는 임시 업로드 토큰**을 받아
   - Supabase 비공개 저장소 `doc-images`에 올리고
   - 입력창의 **글을 쓰던 위치**(커서 위치)에 사진 미리보기 칸을 끼워 넣고, 그 아래 설명 칸에 커서를 둡니다. 화면에는 코드가 보이지 않습니다.
   - 입력창은 글 칸과 사진 칸이 번갈아 나오는 편집 화면이며, 저장 형식은 글 속의 `[[그림:파일명|설명]]` 자리표로 같습니다. 수정 화면에서는 저장된 자리표가 다시 사진 칸으로 복원됩니다. 사진 ✕ 로 빼면 앞뒤 글 칸이 합쳐집니다.
2. 챗봇은 문서 글을 AI(Gemini)에 보낼 때 자리표와 설명을 글로 함께 보냅니다. **사진 자체는 보내지 않습니다.**
3. AI가 답변에 `[[그림:파일명]]`을 넣으면, 화면이 서버(`/api/doc-image-url`, 로그인한 사용자만)에서 **5분짜리 임시 주소**를 받아 사진을 보여 줍니다. 누르면 크게 봅니다. (답변당 최대 20장. 넓은 질문에는 해당 항목을 빠짐없이 모두 보여 주도록 AI에게 지시)
   형식이 틀리거나 없는 파일명은 화면에서 조용히 사라지고, 음성 읽기에서도 읽지 않습니다.
   임시 주소가 만료돼 사진이 안 열리면 한 번 새 주소를 받아 다시 시도하고, 그래도 안 되면 "사진을 불러올 수 없습니다"를 보여 줍니다.

## 보안 (2차 방식: 비공개 + 임시 주소)
- 버킷은 **비공개**이고 브라우저(anon)용 정책이 없습니다. 파일 주소를 알아도 임시 서명이 없으면 열리지 않고, 목록 조회·수정·삭제도 불가합니다.
- 열람: 로그인 토큰(자료실 로그인과 같은 토큰, 8시간) + 서버가 회원 상태를 DB에서 다시 확인 → 5분 임시 주소. 주소가 외부로 새어도 5분 뒤 무효입니다.
- 업로드: 관리자 확인 후 서버가 파일명과 임시 토큰 발급. 화면이 이름을 정할 수 없고, 한 장 2MB 이하, webp/jpg만.
- 같은 사진의 임시 주소는 화면 메모리에 최대 4분 남짓 재사용하고, 로그아웃하면 지웁니다.
- 한계: 로그인한 사용자라면 어느 문서의 사진이든 파일명을 알면 열 수 있습니다(제품군/그룹별 제한은 하지 않음). 챗봇 로그인 자체가 브라우저에서 평문 비교하는 구조라는 별도 보안 과제는 그대로입니다.
- 문서를 지우거나 사진을 글에서 빼도 저장소의 파일은 남습니다(빈 공간 낭비). 필요하면 주기적으로 정리합니다.

## 필요한 서버 설정 (Vercel 환경변수 — 자료실과 공용)
`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `LIBRARY_TOKEN_SECRET`(32자 이상 무작위). 문서 사진만 쓸 때는 R2 관련 값이 필요 없습니다.
설정 전에는 사진 올리기/보기에 "자료실 기능이 아직 설정되지 않았습니다" 안내가 나오고, 글 부분은 평소처럼 동작합니다.

## 비용·용량
- Supabase 무료: 저장 1GB, 월 전송 5GB. Pro($25/월): 저장 100GB, 전송 250GB.
- 1000px WebP 한 장은 대략 30~120KB. 관리자 대시보드에 "문서 사진 저장소" 에너지바가 표시됩니다.
