# 원본 자료실 설정 방법 (직접 하셔야 하는 부분)

코드는 모두 준비되어 있습니다. 아래 **세 곳의 설정**을 하셔야 자료실이 실제로 동작합니다.
비밀 값(키)은 **채팅이나 문서에 붙여넣지 말고** 각 서비스 화면에만 입력하세요.

## 1. Supabase (데이터베이스) — SQL 실행

1. Supabase 대시보드 → `cuckoo-proguide` 프로젝트 → **SQL Editor**
2. `docs/sql/library_01_tables.sql` 내용을 붙여넣고 **Run**
3. `docs/sql/library_02_rls.sql` 내용을 붙여넣고 **Run**  (브라우저에서 자료실 테이블에 접근하지 못하게 막는 설정)
4. (선택) `docs/sql/library_03_user_id_cascade.sql` — 회원 아이디를 바꿔도 문의·대화이력·그룹 기록이 따라오게 하는 설정

## 2. Cloudflare R2 (원본 파일 저장소)

1. Cloudflare 대시보드 → **R2 Object Storage** → **Create bucket** (이름 예: `proguide-library`)
   - **공개 접근(Public access)은 켜지 마세요.** 비공개 그대로 둡니다.
2. R2 화면의 **Manage API tokens**(API 토큰 관리) → **Create API token**
   - 권한: **Object Read & Write**, 적용 대상: 위에서 만든 **버킷만**
   - 생성 직후 한 번만 보이는 **Access Key ID**, **Secret Access Key**를 복사해 둡니다.
   - **Account ID**는 R2 개요 화면 오른쪽에 표시됩니다.
3. 버킷 → **Settings → CORS policy**에 아래를 붙여넣습니다 (브라우저가 파일을 올리고 읽을 수 있게 허용하는 설정).
   ```json
   [
     {
       "AllowedOrigins": ["https://fieldmind-one.vercel.app"],
       "AllowedMethods": ["GET", "PUT", "HEAD"],
       "AllowedHeaders": ["*"],
       "ExposeHeaders": ["ETag", "Content-Length"],
       "MaxAgeSeconds": 3600
     }
   ]
   ```
   - 배포 전 미리보기 주소에서 시험하려면 그 주소(예: `https://fieldmind-git-...vercel.app`)도 `AllowedOrigins`에 추가하세요.

## 3. Vercel (서버 설정값)

Vercel → `fieldmind` 프로젝트 → **Settings → Environment Variables**에 아래 7개를 추가합니다.
적용 환경은 **Production과 Preview 모두** 체크하세요(미리보기에서도 시험하려면). 비밀 값은 **Sensitive** 로 설정하는 것을 권장합니다.

| 이름 | 값 |
|---|---|
| `R2_ACCOUNT_ID` | R2의 Account ID |
| `R2_ACCESS_KEY_ID` | 위에서 복사한 Access Key ID |
| `R2_SECRET_ACCESS_KEY` | 위에서 복사한 Secret Access Key |
| `R2_BUCKET` | 버킷 이름 (예: `proguide-library`) |
| `SUPABASE_URL` | `https://lixiqdhymlefrynleglw.supabase.co` |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase → Project Settings → API → **service_role** (secret) 키 |
| `LIBRARY_TOKEN_SECRET` | 32자 이상의 아무 무작위 문자열 (예: 터미널에서 `openssl rand -hex 32`) |

- `SUPABASE_SERVICE_ROLE_KEY`는 데이터베이스 전체 권한을 가진 키입니다. 절대 공개하거나 코드·채팅에 붙여넣지 마세요. (코드의 `anon` 키와 다른 키입니다.)
- 환경변수는 **저장 후 새로 배포해야** 적용됩니다. (Deployments → 최신 배포 → Redeploy)

## 4. 확인 순서

1. 관리자(`admin`)로 로그인 → 사이드바 **원본 자료실** → `＋ 대그룹 추가`
2. 분류에 `⬆ 자료`로 PDF 하나 업로드
3. 대시보드의 **자료실 파일 저장공간** 막대가 보이는지 확인
4. 일반 사용자 계정으로 로그인 → 하단 **자료실** → 자료를 눌러 열리는지 확인

## 5. 문제가 생기면

| 화면 메시지 | 원인 |
|---|---|
| 자료실 기능이 아직 설정되지 않았습니다 | 서버 함수가 배포되지 않았거나 환경변수가 없음 (3번 확인 후 Redeploy) |
| 서버 설정이 완료되지 않았습니다 | 7개 환경변수 중 빠진 것이 있음 |
| 데이터베이스 오류가 발생했습니다 | 1번 SQL을 아직 실행하지 않았음 |
| 업로드에 실패했습니다 … CORS | R2 버킷의 CORS 설정(2-3)에 현재 주소가 없음 |
| 파일을 불러오지 못했습니다 | R2 CORS, 또는 키/버킷 이름 오류 |
| 로그인 시도가 너무 많습니다 | 잠시(10분) 후 다시 시도 |
