# 문서 관리: 모델 이동·복사, 문서 이동

챗봇용 문서 관리(제품군 › 모델 › 문서)에서 내용을 지우고 다시 입력하지 않고 위치를 옮기는 기능입니다. (원본 자료실과는 별개입니다.)

## 기능
| 하고 싶은 일 | 방법 |
|---|---|
| 모델을 다른 제품군으로 이동 (문서가 모두 따라감) | ① 「⇅ 순서 변경」을 켠 뒤 모델 줄을 다른 제품군의 모델 위, 또는 제품군 줄(빈 제품군 포함) 위로 끌어 놓기 ② 모델 줄의 「↔ 제품군 이동」 버튼 (휴대폰) |
| 모델을 다른 제품군에도 복사 (원본 유지) | 모델 줄의 「⧉ 복사」 버튼 |
| 문서 하나를 다른 모델로 이동 | 모델의 「📝 내용 입력」 창 → 등록된 문서의 「↔ 이동」 |

- 같은 제품군 안에서 모델 순서만 바꾸는 끌기는 예전처럼 확인 없이 저장됩니다.
- 모델 이동은 DB의 `models.product_id`만, 문서 이동은 `documents.model_id`만 바꿉니다. 모델의 문서는 모델에 붙어 있어 그대로 따라갑니다. 복사는 새 모델과 문서(내용 그대로, 새 번호)를 만들고, 문서 복사 중 오류가 나면 만든 것을 지우고 취소합니다. 문서 속 사진은 같은 파일을 함께 사용합니다.
- DB 구조 변경은 없습니다(운영 SQL 실행 불필요).

## 접근 권한 (중요)
사용자 그룹의 접근은 **제품군 단위**(`group_products`)로 정해져 있어서, 제품군이 바뀌면 그 모델·문서를 보는 그룹이 달라집니다.
이동·복사 전에 확인 창에서 **지금 보는 그룹 / 이동 후 보는 그룹**을 보여주고, 새 제품군을 볼 수 있는 그룹이 하나도 없으면 경고합니다.
관리자는 항상 모두 볼 수 있습니다.

## 제한
- 이동할 제품군에 같은 이름의 모델이 있으면 이동할 수 없습니다(이름을 먼저 바꿔야 함). 복사는 이름 뒤에 " (복사)"가 붙습니다.
- 문서 입력창에서 문서를 삭제해도 DB에 반영되지 않는 기존 문제는 이 작업 범위가 아닙니다.
