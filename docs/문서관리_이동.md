# 문서 관리: 선택한 문서를 다른 제품군의 모델로 이동·복사

챗봇용 문서 관리(제품군 › 모델 › 문서)에서, 이미 입력한 문서를 지우고 다시 입력하지 않고 다른 모델로 옮기거나 복사하는 기능입니다.
(원본 자료실과는 별개입니다. "폴더"라는 말이 나오면 원본 자료실이 아니라 이 문서 관리를 뜻할 수 있으니 불분명하면 먼저 물어봅니다.)

## 사용 방법
1. 문서 관리에서 모델의 문서 목록을 펼치고 **문서 체크박스**를 체크합니다. (여러 모델·여러 제품군의 문서를 함께 체크해도 됩니다. 「이 모델 문서 전체 선택」, 위쪽 「전체 선택」도 사용 가능)
2. 위쪽 다운로드 막대의 **「↔ 선택 문서 이동」** 또는 **「⧉ 선택 문서 복사」**를 누릅니다. (체크한 문서가 없으면 버튼이 잠겨 있습니다.)
3. 창에서 **제품군 → 모델**을 고릅니다. (모델이 없는 제품군은 고를 수 없음)
4. 확인 창의 안내(옮길 문서 수, 접근 그룹 변화)를 보고 「이동」/「복사」를 누릅니다.

- 이동: 체크한 문서의 소속 모델(`documents.model_id`)만 바뀝니다. 내용은 그대로입니다.
- 복사: 원본은 그대로 두고 새 번호로 문서를 만듭니다(내용·사진 자리표 그대로, 사진 파일은 함께 사용). 복사 중 저장 오류가 나면 만든 것을 지우고 취소합니다.
- 이미 대상 모델에 있는 문서는 자동으로 제외되고, 같은 제목·분류의 문서가 이미 있으면 알려줍니다(중복되어 보일 수 있음).
- 이동 도중 저장 오류가 나면 거기서 멈추고, 이미 옮긴 문서는 그대로 반영됩니다("N건만 이동하고 저장 오류로 멈췄습니다").
- 끝나면 선택이 해제되고 대상 모델의 문서 목록이 펼쳐져 결과를 바로 볼 수 있습니다.
- DB 구조 변경은 없습니다(운영 SQL 실행 불필요).

## 접근 권한 (중요)
사용자 그룹의 접근은 **제품군 단위**(`group_products`)로 정해져 있어서, 문서가 다른 제품군으로 가면 그 문서를 보는 그룹이 달라집니다.
확인 창에서 **지금 보는 그룹 / 이동 후 보는 그룹**을 보여 주고, 대상 제품군을 볼 수 있는 그룹이 하나도 없으면 "일반 사용자에게는 보이지 않음" 경고를 띄웁니다. 같은 제품군 안에서의 이동은 "접근 권한은 그대로"라고 안내합니다. 관리자는 항상 모두 볼 수 있습니다.
